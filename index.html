Discord Shift Calendar Bot

A private, non-commercial tool for turning work rota screenshots shared in Discord into calendar appointments.

How it works

A permitted user sends a rota screenshot in a private Discord channel. Anthropic’s Claude API identifies shift start and finish times, and the Bot displays them for confirmation. Once approved, the Bot uses Google Calendar to create drop-off and pickup appointments and optionally invite personal and work email addresses.

The Bot is self-hosted on the operator’s Windows computer. It is not open for public registration.

Privacy and permissions

The Bot uses Google Calendar event access to create the requested appointments. Read the Privacy Policy for details about information processed, shared and stored.
